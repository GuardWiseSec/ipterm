How to find your router's IP address

Updated October 12, 2026 · 2 min read

Your router's IP address, also called the default gateway, is the address you type into a browser to open the router's settings page. It is usually 192.168.1.1 or 192.168.0.1, but it varies by brand and internet provider, so the surest way is to ask your device.

Windows

Open Command Prompt or PowerShell and run:

ipconfig

Find the adapter you're connected with (Wi-Fi or Ethernet). The address next to Default Gateway is your router.

Mac

Open System Settings → Wi-Fi (or Network for a cable connection), click Details next to your network, then open TCP/IP. The Router field is the address. In Terminal:

route -n get default | grep gateway

Linux

ip route | grep default

The address after default via is your router.

iPhone and iPad

Go to Settings → Wi-Fi, tap the ⓘ next to your network, and look for Router.

Android

The location varies by phone maker. It is usually under Settings → Network & internet → Wi-Fi (or Connections): tap your network, open its details or advanced options, and look for Gateway or Router.

Common default router addresses

AddressOften used by
192.168.1.1The most common default across many router brands
192.168.0.1Another very common default
10.0.0.1Many internet provider gateways, including Xfinity
192.168.1.254Some provider gateways, including AT&T
192.168.100.1Status pages of many cable modems (separate from the router)

Why the address works for everyone

These are private addresses. They only exist inside your home network, so millions of homes can use 192.168.1.1 at the same time without conflict. That also means nobody can reach your router at that address from the internet, and it can't be traced to a location.

If you can't log in

  • The default username and password are usually printed on a label on the router. If you've never changed them, change them now: a default admin password is one of the most common ways home networks get taken over.
  • Some provider gateways and mesh systems (such as Google Nest Wifi or Eero) are managed through a phone app instead of a web page.
  • If nothing loads, check that you're on the router's network, not mobile data or a VPN.
