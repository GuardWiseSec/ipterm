What is ipterm?

ipterm is a free IP address lookup that works like a terminal. Run whoami to see your public IP address, the network (ISP) it belongs to and its approximate location, check whether your DNS, browser or VPN leaks more than that with leaktest, or look up any IPv4 or IPv6 address, any domain's DNS records, registry (whois) records and any autonomous system (ASN). Every result has its own page you can share. No accounts, no cookies, no tracking.

From the command line

curl %ORIGIN%                     # your IP as plain text
curl %ORIGIN%/json                # your IP details as JSON
curl %ORIGIN%/8.8.8.8             # any IP as JSON
curl %ORIGIN%/AS13335             # any network as JSON
curl %ORIGIN%/dns/example.com     # DNS records as JSON
curl %ORIGIN%/mail/gmail.com      # SPF, DMARC and DKIM check as JSON
curl %ORIGIN%/whois/8.8.8.8       # registry record as JSON
curl %ORIGIN%/whois/example.com   # domain registration as JSON
curl %ORIGIN%/cidr/10.0.0.0/22    # subnet calculation as JSON

IP location is approximate. It usually points to your internet provider's regional hub, not a street address.
